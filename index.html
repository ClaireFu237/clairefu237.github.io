AI Resume Ranking System

Entagile Capstone Project · Feb–Apr 2026

Project Description

Takes PDF or DOCX resumes and a job description, recruiter notes, or both. The system extracts structured candidate profiles, applies required criteria, and uses pgvector similarity search to shortlist candidates. It returns a ranked shortlist with weighted scores and explanations for each criterion.

Result

Tested the full screening workflow locally and on AWS EC2. Compared five LLMs across resume parsing, query rewriting, and candidate scoring. In the parsing benchmark, GPT-5.4-mini took 10.76 seconds versus 34.20 seconds for GPT-5.4.

Natural Language to SQL

Holokai · AI Research & Development Internship · Jun–Aug 2026

Project Description

Takes a plain-English business question and database schema metadata. It generates and validates read-only SQL for PostgreSQL or BigQuery, retries failed queries with SQL repair, and returns the SQL and, when executed, the query results. Database rows stay out of the LLM prompts.

Result

On a benchmark of 12 business questions against a 32-table mock database, the selected configuration for each engine answered 11 of 12 questions correctly (92%). Average LLM response time per question was 5.94 seconds for PostgreSQL and 10.98 seconds for BigQuery.

Biomedical Literature Retrieval

Johns Hopkins University · NLP Team Project · Jan–Apr 2026

Project Description

Takes a biomedical question from BioASQ Task 13b and returns a ranked list of relevant PubMed articles using their titles and abstracts. The system uses a SciBERT retriever trained with hard negatives and reranks candidates by combining semantic similarity with keyword overlap.

Result

Retrieval fine-tuning raised Hit@1 from 9% to 84% on the original corpus. On the corpus augmented with 1,000 distractor documents, hard-negative training and reranking raised Hit@1 from 82% to 92% and reached an MRR@20 of 0.9342.
